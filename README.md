# PsychoHUB

**Твой компьютер. Твои правила. Максимум контроля.**

Оптимизатор Windows 10/11 для игр — в первую очередь GTA 5 / Majestic RP. Подбирает настройки под конкретное железо, а не применяет одно и то же всем подряд: для каждой настройки PH показывает, рекомендуется ли она именно вашему ПК или ноутбуку, и почему.

## ⬇ Скачать

**[Последняя версия → PsychoHUB.exe](https://github.com/Prokurennyy/PsychoHUB/releases/latest)**

Один портативный файл: устанавливать ничего не нужно, .NET уже внутри. Требуется Windows 10/11 (64-бит) и права администратора. Дальше PH обновляется сам.

> При первом запуске Windows SmartScreen может предупредить о неизвестном издателе: «Подробнее → Выполнить в любом случае». Так бывает с любыми программами без платной цифровой подписи, которые просят права администратора.

## Что умеет

- **Подбор под железо** — ПК и ноутбуки отдельно, электропитание, службы, фоновые задачи, сеть, ввод. Quick Boost применяет только рекомендованное.
- **Игровой режим** — авто-буст (фоновые программы ниже, игра и Discord выше), очистка оперативной памяти, точный таймер Windows, лучшие ядра процессора для игры (Intel P-ядра, AMD X3D), профиль драйвера NVIDIA для игры (низкая задержка, лимит FPS).
- **Игровые сессии** — после игры сводка: средний FPS, 1% low, рывки, пинг, температура и сброс частот видеокарты и процессора, с объяснением причин.
- **Анализ задержек** — какой драйвер вызывает микрофризы (DPC/прерывания) и что с этим сделать.
- **Сеть** — пинг до роутера и интернета: сразу видно, лагает интернет или компьютер.
- **Majestic RP** — безопасная очистка кэша клиента и проверка настроек графики GTA.
- **Для опытных** — обновления Windows, VBS/HVCI, MSI-режим и другое. Отдельно, с предупреждениями.
- **Фоновый режим** — работает из трея, запуск вместе с Windows.

## Безопасность

- PH меняет только настройки Windows и драйвера. Файлы игры не изменяются, в процесс игры ничего не внедряется, драйверов ядра нет.
- Перед изменением сохраняется исходное значение — любую настройку можно откатить одной кнопкой, предлагается точка восстановления Windows.
- **Аварийный откат:** ярлык «PH — аварийный откат» (создаётся в разделе «Безопасность и откат») или `PsychoHUB.exe --revert-all` возвращает всё как было, даже если окно программы не открывается.
